# Futureforce Spring Boot Lesson App

このプロジェクトは、Spring Boot を使用したメモ管理アプリケーションの学習用リポジトリです。  
Git、GitHub、および Eclipse（日本語設定）の基本的な使い方を学ぶためのガイドとしてこの README を活用してください。

## 1. アプリケーションの実行方法

Eclipse で Spring Boot アプリケーションを起動する手順は以下の通りです。

1. **アプリケーションの起動**:
   - `src/main/java/com/lesson/memo/FutureforceSpringbootLessonAppApplication.java` を右クリックします。
   - `実行` > `Spring Boot アプリケーション` を選択します。
2. **動作確認**:
   - ブラウザを開き、`http://localhost:8081` にアクセスします。

---

## 2. Eclipse での Git 操作（ステージング・コミット・プッシュ）

コードを変更した後、リモートリポジトリ（GitHub）に反映させる手順です。

1. **Git ステージング・ビューを表示**:
   - `ウィンドウ` > `ビューの表示` > `その他...` を選択します。
   - `Git` > `Git ステージング` を選択して開きます。
2. **ステージング (Add)**:
   - `ステージングされていない変更` にある変更したファイルを、`ステージング済みの変更` 欄にドラッグ＆ドロップ（または「＋」ボタンをクリック）します。
3. **コミット (Commit)**:
   - `コミット・メッセージ` 欄に変更内容を記入します。
      - 例）〇〇機能を追加しました。
   - `コミット` ボタンをクリックしてローカルリポジトリに保存します。
4. **プッシュ (Push)**:
   - `コミットおよびプッシュ` ボタンをクリックするか、プロジェクトを右クリックして `チーム` > `リモート` > `プッシュ...`（または `origin へプッシュ`）を選択して GitHub へ送信します。

---

## 3. Pull Request (PR) の作成方法

GitHub 上で自分の変更を他の人に確認してもらい、統合するための手順です。

1. **GitHub を開く**:
   - 自分のリポジトリのページ（GitHub）にアクセスします。
2. **PR の作成**:
   - プッシュ直後であれば、「Compare & pull request」という黄色いバーが表示されるので、それをクリックします。
   - 表示されない場合は、`Pull requests` タブから `New pull request` をクリックします。
3. **内容の確認と送信**:
   - `base: main`（統合先）と `compare: [自分のブランチ名]`（自分の変更）が正しいことを確認します。
   - タイトルと説明を記入し、`Create pull request` をクリックして完了です。
4. **Futureforceにて課題提出**
   - 該当の課題ページのチャットにて、PR作成時のURLを添付し提出してください。
   - 例）  
      課題提出をいたします。ご確認お願いいたします。  
      https://github.com/username/futureforce-springboot-lesson-app/pull/〇  
      ※usernameには自身のGithubアカウント名、〇には特定の数字が入ります。

---

## 4. ブランチの切り替え方法

次の課題に進む際は、ブランチを切り替えて作業します。

1. **ブランチの作成・切り替え**:
   - プロジェクトを右クリックし、`チーム` > `切り替え` を選択します。
   - 既存のブランチ（例: `main`）に戻る場合は、リストから対象のブランチ名を選択します。
